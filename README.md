# 🍬 お菓子業界 商品・見積管理システム

お菓子業界のメーカーと問屋をつなぐB2B商品管理・見積システム

## ✨ 主な機能

### 📦 商品コード自動生成システム
- メーカーコード + カテゴリコード + 連番の形式
- 例: `HK-AM-0001` (星空製菓 - 飴 - #1)
- 商品登録時に自動生成

### 🔍 強化された検索・フィルター
- **検索対象**: 商品名・メーカー名・商品コード
- **価格フィルター**: 5段階の価格範囲（〜500円、500-1000円など）
- **カテゴリフィルター**: 飴、チョコ、クッキー、せんべい、その他
- **メーカーフィルター**: 20社から選択
- **並び替え**: 登録日・価格（昇順/降順）

### 👥 ユーザー種別
- **メーカー**: 商品登録・管理、見積依頼対応
- **問屋**: 商品カタログ閲覧、見積依頼送信

## 🚀 ローカル実行方法

### 方法1: Pythonを使用
```bash
cd Mitsumori3
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を開く

### 方法2: Node.jsを使用
```bash
npx http-server -p 8000
```

## 🎯 使い方

### メーカーとしてログイン
1. ロール選択: 「メーカー」
2. 会社選択: 任意のメーカーを選択
3. **商品登録**: カテゴリを選択すると商品コードが自動生成
4. **登録商品一覧**: 自社の商品を確認・削除
5. **受信見積依頼**: 問屋からの依頼に対応

### 問屋としてログイン
1. ロール選択: 「問屋」
2. 会社選択: 任意の問屋を選択
3. **商品カタログ**: 全メーカーの商品を検索・閲覧
4. **フィルター機能**: メーカー・カテゴリ・価格範囲で絞り込み
5. **見積依頼**: 気になる商品の見積を依頼
